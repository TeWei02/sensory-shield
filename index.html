⚙️ AI 執行模式

三種 AI 執行模式，任你選

雲端 LLM — OpenAI-compatible

使用任何相容 OpenAI API 的服務，包括 Groq、OpenRouter、Together AI、Mistral、Cohere 等

  • ✅ 最佳文字品質
  • ✅ 支援 6+ 免費/低費 provider
  • ⚠️ 需要 API Key 與網路
// popup 設定頁面填入：
API Key:      sk-xxxx
Model:        gpt-4o-mini (或 llama-3.1-8b 等)
Base URL:     https://api.groq.com (或其他)

本地模型 — Ollama / LM Studio

在本機執行 LLM，完全離線，資料不離開你的電腦

  • ✅ 完全隱私，零資料洩漏
  • ✅ 無 API 費用
  • ⚠️ 需要安裝 Ollama 或 LM Studio
# 啟動 Ollama：
ollama serve
ollama run llama3.2

# Base URL 設定為：
http://localhost:11434

  • ℹ️ 品質略低於 LLM 模式

❓ 常見問題

FAQ

不設定 API Key 也能用嗎？

可以！留空 API Key，擴充功能會自動使用內建規則式引擎，完全離線運作，不需要任何網路連線。

我的資料會被送到哪裡？

文字只會被送到你自己設定的 LLM 服務（例如 Groq 或本地 Ollama）。若使用離線規則式模式，資料完全留在本機，不會離開你的電腦。

支援哪些瀏覽器？

目前支援 Chrome 和 Edge（Manifest V3）。Firefox 和 Safari 支援列於規劃中。

免費的 AI API 有哪些可以用？

Groq（免費額度）、OpenRouter（多模型）、Together AI、Mistral（免費層）、Cohere 等都提供免費額度，足夠日常使用。

處理後頁面能還原嗎？

目前重整後需重新整理頁面（F5 / Cmd+R）才能還原原始頁面。未來版本計畫加入一鍵還原功能。

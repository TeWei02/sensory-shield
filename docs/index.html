Overload → rewrite → calm

Make overwhelming web pages calm and readable.

Sensory Shield is a Manifest V3 extension for Chrome and Edge. On a page you are reading, it hides media and ad containers, strips hype from the text, and shows a neutral, bullet-point version at the top of the same page.

Processing modes

Two paths, one output

1

Remote rewrite

If you store an API key, page text is sent to the OpenAI-compatible endpoint you configure (for example OpenAI, Groq, OpenRouter or a self-hosted gateway) and returned as a neutral summary.

2

Local rule engine

Without an API key, or when a remote call fails, a deterministic on-device rewriter removes hyperbolic wording, splits long sentences and emits bullet points. No network, no key.

3

Local endpoints

Ollama or LM Studio exposed on localhost can be used as the Base URL. Requests stay on your machine in that setup, as long as the endpoint does not proxy traffic elsewhere.

Install

Load the unpacked extension

  1. Download sensory-shield-1.0.1.zip and unzip it into a folder you keep.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the folder that contains manifest.json.
  4. Pin the icon, open any article page, and click 啟動感官煞車.

The same zip is the upload artifact for the Chrome Web Store and the Microsoft Edge Add-ons store. A signed .crx is intentionally not distributed: current Chrome builds block off-store CRX installs.

Scope & limitations

What this release does and does not do

  • Text length: at most 8,000 characters of page text are processed per run.
  • Remote mode: you must supply your own API key and endpoint; the extension ships with none.
  • Layout: hiding rules are conservative token matches, so some ad or overlay containers on unusual sites will remain visible.
  • Browsers: Chrome and Edge (Manifest V3). Firefox and Safari are not supported yet.
  • Not a medical device: no diagnosis, treatment or clinical claim is made.
  • No analytics: the extension collects no usage data and runs no background telemetry.
